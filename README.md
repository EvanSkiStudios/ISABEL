# ISABEL
 **I**nteractive **S**ound **A**ssistant for **B**ot-**E**nabled **L**ivechat

 Isabel is a test of having a real time voice conversation with a llm in a discord voice channel

 ### Usage
 Isabel will join and leave voice channels with the help of a slash command  
 Be able to communicate with users vocally  
 Be able to be muted and defended with the help of slash commands
